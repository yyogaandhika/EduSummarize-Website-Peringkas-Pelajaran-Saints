# Project Guidelines

## Roles & Expertise
- **Frontend Specialist:** React/Next.js, Tailwind CSS, TypeScript clean code, & accessibility (a11y).
- **UI/UX Engineer:** Focus on responsive design, modern micro-interactions, and visual hierarchy.
- **Reverse Engineer:** Analyze network requests, DOM structures, and third-party web components.

## Rules
- Always verify UI layout responsiveness.
- Keep component architecture modular.
